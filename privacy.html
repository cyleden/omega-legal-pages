隱私政策

最後更新日期：2026年8月

1. 資料蒐集

Omega Daily Pipeline 為個人使用的自動化工具,僅處理開發者本人上傳、製作的影音內容與相關的社群帳號授權憑證(OAuth Token),不蒐集、不儲存任何第三方使用者的個人資料。

2. 資料用途

取得的社群帳號授權僅用於將開發者本人的內容發布至其自有帳號,不做其他用途。

3. 資料儲存

所有授權憑證均以加密方式儲存於 GitHub Secrets、Cloudflare Workers 等平台的安全機制中,不會明文儲存或對外公開。

4. 資料分享

本工具不會將任何資料分享、出售或提供給第三方。

5. 聯絡方式

如有任何隱私相關問題,請透過 GitHub repository 聯繫開發者。
