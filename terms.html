服務條款

最後更新日期：2026年8月

1. 服務說明

Omega Daily Pipeline 是一套個人使用的內容自動化工具，用於將使用者自行製作、擁有著作權的短影音內容，發布至使用者自己的社群媒體帳號（包含但不限於 YouTube、TikTok、Instagram）。本工具僅供開發者本人使用,不對外提供公開服務或帳號代管服務。

2. 使用範圍

本工具僅串接開發者本人授權的社群帳號,不會存取、發布或修改任何第三方帳號的內容。

3. 內容責任

所有透過本工具發布的內容,其著作權與內容責任均歸屬於開發者本人。

4. 服務變更

本工具可能隨時調整、暫停或終止,不另行通知。

5. 聯絡方式

如有任何問題,請透過 GitHub repository 聯繫開發者。
